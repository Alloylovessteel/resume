# Portfolio Admin Dashboard

A static editing dashboard for https://alloylovessteel.github.io/resume/.

Click a text block in the preview and choose **Edit Text**. The dialog edits the selected block in one rich text box. It includes controls for font, size, text colour, bold, italic, underline, alignment, and link destination. Use the preview toggle to check desktop and mobile layouts.

The dashboard can also reorder or hide sections and add a custom text section. Connect with a fine-grained GitHub personal access token restricted to `Alloylovessteel/resume` with **Contents: Read and write**. Saving commits the updated portfolio page to GitHub; Pages publishes it. The token stays in the current browser tab's memory. Never put it in the hosted files or commit it; revoke it when no longer needed.

This is a static app without a server or database. To make the dashboard available online, publish this folder as a static site on a separate host. A provider's free plan can change.

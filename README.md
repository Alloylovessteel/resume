# Aloysius Yeow Portfolio

Static resume and portfolio website. Open `index.html` locally or deploy this folder with a static hosting provider such as AWS Amplify Hosting.

The contact form opens a prefilled email draft using the visitor's email app. It does not send or store submissions. Replace the initials profile placeholder with a profile photo when ready.

Before making a public repository, confirm you want the downloadable resume shared publicly; the resume includes your phone number.

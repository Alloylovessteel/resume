# Aloysius Yeow Portfolio

A responsive, accessible static resume and portfolio website. Open `index.html` locally to preview it. The downloadable resume is included as `resume.pdf`.

The contact form opens a prefilled email draft in the visitor’s email app. The site does not send or store messages. Replace the initials avatar with a profile photo when ready.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive visual design and themes
- `script.js` — mobile navigation, theme preference, and email-draft form
- `resume.pdf` — public resume with phone number removed

This static site has no server, database, or third-party form processor.
